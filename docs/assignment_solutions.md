# Assignment 1 — Written Solutions

## Q1. Algorithm to calculate total marks and percentage in five subjects

Algorithm: Calculate Total Marks and Percentage in Five Subjects

1. Start.
2. Input marks of five subjects: m1, m2, m3, m4, and m5.
3. Calculate total = m1 + m2 + m3 + m4 + m5.
4. Calculate percentage = (total / 500) * 100.
   (Assumption: each subject is out of 100 marks.)
5. Display total and percentage.
6. Stop.

## Q2. Algorithm to calculate an electricity bill

Algorithm: Calculate Electricity Bill

1. Start.
2. Input consumed units and price per unit.
3. Calculate bill = consumed_units * price_per_unit.
4. Display the electricity bill.
5. Stop.

Note: This is a basic calculation before taxes, fixed charges, or other adjustments.
