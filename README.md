## How to view the flowcharts

Open the two `.md` files in GitHub. GitHub supports Mermaid diagrams in Markdown and should render the flowcharts automatically.

## How to compile and run a C++ program

If a C++ compiler such as `g++` is available:

```bash
g++ cpp_programs/Q5_student_information.cpp -o program
./program
```

Replace the source filename with the program you want to run. On Windows, run `program.exe` instead of `./program`.

- **Q2:** The basic bill is consumed units multiplied by price per unit. Taxes, fixed charges, and other adjustments are not included because the question does not specify them.
